## 归类规则

- Q 版不单列角色：小号 / 超小号 / 小傻子版放进对应角色的 `chibi/`。
- DeepClaude 是 DeepSeek 的变体，目录为 `deepseek/variants/deepclaude/`。
- 触手怪是 Claude 的特殊形态，目录为 `claude/variants/tentacle-form/`。
- 没有素材的设定不建空目录。
