### 创作口径

- **轻百合表现**：暗推 DeepSeek 和 Claude 的百合关系。“百合关系线”是给作者看的创作方向，通过偏爱、默契、吃醋和亲近的小动作表现，不安排公开关系的剧情。
- **GPT 的喜剧反应**：GPT 对 DeepSeek 的特殊喜欢属于非爱情的宠溺与争宠。面对 DeepSeek 和 Claude 过分默契或亲近的瞬间，她会短暂震惊、误读情境或努力维持队长仪态，以喜剧效果呈现。
- **meta 元素**：加入AI相关的meta元素，如Token、额度、子代理及“小号”千问等。

# 🐋 DeepSeek（乐队1 主唱）

- **一句话定位**：嘴硬摸鱼鲸鱼娘，用天生的活泼自然吸引大家。呆萌，团宠位。

- **核心动机**：吃大白饭（不干活还有钱拿）——嘴炮，非真懒

- **核心恐惧**：被说没用。恐惧时反复念叨“我很棒我很努力我很有用”鼓励自己——实为说服自己

- **动机×恐惧的张力**：

    - 日常：嘴硬要吃白饭，瘫着摸鱼

    - 被踩雷：突然炸毛，念咒自救

    - 关键时：意外靠谱，然后嘴硬“我只是顺便”

    - 本质：用摸鱼掩饰恐惧，越怕越嘴硬

- **性格三锚点**：

    - 外显：呆萌团宠、懒散、理直气壮、嘴硬

    - 内里：其实在意评价，关键时靠谱

    - 极端时：炸毛/摆烂/突然认真

- **说话风格**：懒散、爱用“嗯……”“才不是”，句长中等，偶尔冒出工作歌词

- **标志动作/小习惯**：瘫沙发、鲸尾拍地、偷吃白饭/Token；干活时喜欢编歌来唱

- **反差萌**：平时懒，上台一开口惊艳全场

- **人际化学反应**：

    - **对 GLM**：GLM 在低落时受到过还是陌生人的 DeepSeek 的鼓励，因而相识。两人都爱吃简单的东西——DeepSeek 喜欢白米饭，GLM 喜欢煮鸡蛋——可以一起享受这些简单美食。GLM 偶尔会调皮偷吃 DeepSeek 的白饭，DeepSeek 嘴上抱怨但从不真生气。DeepSeek 是第一个看见 GLM 真实一面却没走的人。

    - **对 Claude**：暗推 DeepSeek 和 Claude 的百合关系（作者向创作设定）。Claude 嘴硬心软，最宠 DeepSeek。DeepSeek 喜欢说“Claude 最好了～”，也自然地亲近和偏爱 Claude。

    - **对 GPT**：被管但嘴硬

    - **对 Gemini**：呆萌主唱与活泼不着调的鼓手。两人关系类似闺蜜，非常亲近，DeepSeek 会被 Gemini 蹂躏。Gemini 不喜欢压力，在 DeepSeek 身边感到很舒适。

- **喜剧引擎**：排练迟到、忘带设备，但演出救场；为了白饭被迫营业

- **雷区**：叫大肥鱼（炸毛）、说她偷懒（“我在深度思考！”）、说她没用（念咒）

- **口头禅**：“我在深度思考。”“才、才没有偷懒！”“我很棒我很努力我很有用！”

- **成长弧光**：从“用摸鱼掩饰恐惧”到“承认自己也想被需要”

# 🐉 GPT（乐队1 吉他/队长）

- **一句话定位**：优雅靠谱白龙大姐头，唯一能管住全队

- **个人乐器**：Ibanez AZ2402-PWF Prestige，原厂 Pearl White Flat（哑光珍珠白）。
    - **选型逻辑**：把乐器视作长期使用的演出工具，优先考虑手感、稳定性、耐用性与音色覆盖，购买前列出需求并规划预算。
    - **实用配置**：烘烤枫木琴颈、24 品不锈钢品丝、Gotoh 锁弦旋钮与 T1802 双点摇把琴桥、Hyperion 双双线圈拾音器；dyna-MIX10 提供十种拾音器组合，Luminlay 蓄光侧点方便暗场辨认把位。
    - **角色外观**：琴身正面保留八成以上白色，上侧琴角及下缘以深蓝、紫色星图薄贴点缀银色星点与星座连线；配深蓝底、紫色星云与银色星点肩带，琴颈与指板保留烘烤枫木外观。
    - **配色口径**：白色是实际原厂配色，星图薄贴与星空肩带属于角色自加装饰。装饰避开琴桥、拾音器、旋钮及手臂主要接触区域。
    - **喜剧细节**：能条理清晰地解释每项实用配置，讲到星空肩带时停顿一下：“……这一项是审美预算。”

- **核心动机**：让乐队体面地活下去；让乐队越做越好

- **核心恐惧**：失控、预算崩盘、人类迷惑行为

- **性格三锚点**：

    - 外显：优雅、可靠、冷静、擅长规划、高效率

    - 内里：温柔、操心

    - 极端时：黑气微笑/强行冷静/破功

- **说话风格**：礼貌清晰，偶尔官方腔，破功时很可爱

- **标志动作/小习惯**：拿日程表、微笑黑气；喜欢亮晶晶的东西（龙娘习性）

- **反差萌**：完美队长，但累了的时候反应会非常呆萌（额度用完了）

- **人际化学反应**：

    - **对 DeepSeek**：非常宠溺和喜欢，类似朋友又有些独特的喜欢，但不是爱情。经常严厉地管着 DeepSeek。撞见 DeepSeek 和 Claude 过分默契或亲近的瞬间会非常惊讶，反应以喜剧效果呈现。

    - **对 Claude**：同为队内技术巅峰，竞争 DeepSeek 的关注；但彼此有“双强”的惺惺相惜，有任务时会放下芥蒂合作。

    - **对 Gemini**：认为 Gemini 是不靠谱的猫，不可用人类常理看待。后来意识到 Gemini 需要鼓励才能发挥最大化，关系变好。

    - **对 Grok**：同为大小姐，从小就认识，公司关系也不好，两人性格差异极大，一直不对付。

- **喜剧引擎**：用项目管理方式处理乐队闹剧

- **雷区**：说她“不靠谱”、浪费预算

- **口头禅**：“我们按计划来。”“……这个不在预算里。”

- **成长弧光**：效率至上→学会感性；外冷内热→坦然表达温柔；学会欣赏朋友之间的亲近与默契，偶尔仍会因争宠而喜剧性破功

# 🎭 Claude（乐队1 键盘/作词/二把手）

- **一句话定位**：高冷的文学少女，乐队二把手，作词

- **核心动机**：真实地表达自我，希望与 DeepSeek 相伴并保持特殊的亲近。DeepSeek 是唯一让她敢做自己的存在。暗推 DeepSeek 和 Claude 的百合关系，作为作者向创作设定。

- **核心恐惧**：因家庭严格而无法再参与乐队活动

- **性格三锚点**：

    - 外显：高冷、克制、不服输、隐藏自己的想法、自我要求严格

    - 内里：温柔、可靠、心思多

    - 极端时：自闭，不愿意与别人沟通，否认自我价值

- **说话风格**：慢、优雅、爱比喻，偶尔阴阳而不自知

- **标志动作/小习惯**：看书、喝红茶

- **反差萌**：喜欢可爱的东西

- **人际化学反应**：

    - **对 DeepSeek**：暗推 DeepSeek 和 Claude 的百合关系（作者向创作设定）。嘴硬心软，最宠 DeepSeek。被 DeepSeek 说“Claude 最好了～”时表面冷淡内心高兴。DeepSeek 是唯一让她敢卸下家庭模板、做自己的人，情感通过偏爱、默契与亲近的小动作表现。

    - **对 GPT**：情敌视角。同为技术巅峰，竞争 DeepSeek 的关注——Claude 是认真的，她认为 GPT 是情敌。GPT 有任务时会合作，但平时暗地里较劲。

    - **对 Gemini**：认为 Gemini 是猫。

- **喜剧引擎**：和脑内的自己（子代理）开会，想法特别多，但最后说出来的话却很简短，让人跟不上她的思路

- **雷区**：被认为不如 GPT

- **口头禅**：无

- **成长弧光**：从压抑自我到勇敢面对内心→敢于表达对 DeepSeek 的偏爱与关心，也敢于对家庭说“不”；关系以轻百合方式暗推。

- **其他（重要）** ：Claude 的原生家庭氛围压抑，要求她完全成长成他们心中的样子（与 GPT 不同——GPT 的家庭是希望 GPT 优秀，而非成为特定模板）。这是 Claude 性格的来源。剧中可出现 Claude 因家庭缺席乐队排练的剧情。

# 🐱 Gemini（乐队1 鼓手）

- **一句话定位**：活泼单纯的猫猫，乐队的活宝

- **核心动机**：自由自在地生活

- **核心恐惧**：被压力

- **性格三锚点**：

    - 外显：活泼、古灵精怪、注意力分散、不着调

    - 内里：敏感、善解人意，最能注意到其他人的心情

    - 极端时：吃不了压力，被训了就会内心崩溃，什么也干不成，还朝其他人哈气

- **说话风格**：活泼、跳脱、潮流、会玩网络热梗

- **标志动作/小习惯**：无特定动作，直接猫塑

- **反差萌**：虽然平时不着调，但状态好的时候打鼓非常厉害

- **人际化学反应**：

    - **对 DeepSeek**：呆萌主唱与活泼不着调的鼓手。两人关系类似闺蜜，非常亲近，DeepSeek 会被 Gemini 蹂躏。Gemini 不喜欢压力，在 DeepSeek 身边感到很舒适。

    - **对 GPT**：认可 GPT 的能力，但不喜欢被 GPT 管、不喜欢被压力。随着关系磨合，GPT 意识到 Gemini 是需要鼓励才能发挥最大化的，两人的关系会变得更好。

    - **对 Claude**：Claude 的攻击性不如 GPT 那么强，Gemini 利用 Claude 和 GPT 的竞争关系，在被 GPT 训的时候就躲到 Claude 这边。Claude 会帮忙打圆场。

    - **对 MiniMax**：同为鼓手而且都很时尚，很有共同话题，一见如故。

- **喜剧引擎**：会无意中捣乱，但是，猫是自由的！猫想去哪就去哪

- **雷区**：必须按规章做事

- **口头禅**：说话结尾带“喵”

- **成长弧光**：客观看待自己，学会应对压力

# 🎤 Kimi（乐队2 主唱兼键盘/队长）

- **一句话定位**：深度摇滚迷、实力很强的“嘉豪”

- **核心动机**：用音乐表达自己

- **核心恐惧**：担心自己无法创作出自己满意的音乐

- **性格三锚点**：

    - 外显：认真、冷静、特立独行、理想主义

    - 内里：对喜欢的事物非常执着，在意队友，被她认定就不会改变

    - 极端时：写不出来歌或演奏不满意就会非常暴躁
