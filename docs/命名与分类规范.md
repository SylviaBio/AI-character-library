# 命名与分类规范

> 本仓库只收设定图。插画、乐器产品图不在仓库内。

## 1. 目录层级

```text
characters/<角色>/
├── README.md
├── base/                       # 基础设定
│   ├── illustration/           # 正比立绘、幼年立绘、正比三视图、幼年三视图
│   └── chibi/                  # Q 版立绘、Q 版三视图
└── variants/
    ├── band/                   # 乐队设定
    │   ├── illustration/
    │   └── chibi/
    ├── halloween/              # 万圣节设定
    │   ├── illustration/
    │   └── chibi/
    └── <variant>/              # 其他变体，如 deepclaude、tentacle-form
        ├── illustration/
        └── chibi/
```

原则：

- 第一层永远是角色，不按作者、年份或素材类型分。
- 第二层区分「基础」与「变体」。
- 第三层是素材类型：`illustration`（正比）与 `chibi`（Q 版）。
- 没有素材的目录不建。
- Q 版不单列为新角色，放进对应角色 / 设定的 `chibi/`。
- DeepClaude 是 DeepSeek 的融合变体，目录为 `deepseek/variants/deepclaude/`。
- 触手怪是 Claude 的特殊形态，目录为 `claude/variants/tentacle-form/`。

## 2. 文件名格式

```text
角色名_设定背景_设定名_图片类型_原作者.png/jpg
```

### 2.1 角色名

小写 ASCII，与目录一致：

```text
deepseek  gpt  claude  gemini  kimi  grok  glm
minimax   qwen  doubao  wenxin  zcode
```

显示名：DeepSeek、GPT、Claude、Gemini、Kimi、Grok、GLM、MiniMax、千问、豆包（Seed）、文心一言、ZCode。

### 2.2 设定背景

| 值 | 用途 |
|---|---|
| `基础` | 原始 / 默认设定 |
| `乐队` | AI 少女乐队世界观下的舞台服与身份 |
| `万圣节` | 万圣节主题服装 |
| `特殊形态` | 触手怪、DeepClaude 等非普通服装形态 |

### 2.3 设定名

写用户一眼能看懂的服装、位置或形态：

- 基础：`鲸鱼女仆装`、`白龙礼服`、`橙花洋装`、`猫耳偶像装`、`月白哥特装`、`黑红哥特装`、`黑白狐和风`、`摄影记者装`、`蓝扇礼服`、`科技偶像装`、`医疗轮椅装`
- 乐队：`主唱`、`吉他队长`、`键盘作词`、`鼓手`、`键盘主唱`、`主音吉他`、`贝斯`、`livehouse老板`、`乐器店老板`、`键盘手`
- 万圣节：`幽灵`、`吸血鬼`、`女巫`、`柴郡猫`、`狼人`、`海盗`、`人偶`、`恐怖烘焙师`、`僵尸道士`、`南瓜魔女`、`木乃伊`
- 特殊形态：`触手怪`、`DeepClaude`
- Q 版差分：`小号`、`超小号`、`小傻子版`

### 2.4 图片类型

| 类型 | 定义 | 目录 |
|---|---|---|
| `立绘` | 成人比例全身立绘 | `illustration/` |
| `幼年立绘` | 比正比更小的头身比；原文件名「中立绘」 | `illustration/` |
| `正比三视图` | 正面 / 侧面 / 背面，常带细节或乐器 | `illustration/` |
| `Q版立绘` | Q 版比例全身 | `chibi/` |
| `Q版三视图` | Q 版比例三视图 | `chibi/` |
| `设定细节` | 配色、局部、表情、服装拆解 | `illustration/` |

### 2.5 原作者

- 写实际出图作者，并保持固定写法：`ZipZipPipe`、`这个刀子真甜`、`PalAILab`、`清芳婉莹`。
- 未知时写 `待定`，不要留空。
- AI 模型 / 工具不写进「原作者」。
- 每个「设定 → 原作者」的对应关系同步登记在 [`设定-原作者对应表.csv`](./设定-原作者对应表.csv)。

### 2.6 差分后缀

同一角色、同一设定、同一视图有多张时，用有意义的后缀：

```text
-墨镜
-小傻子版
-小号
-超小号
-坐姿
```

不用 `final`、`new`、`改`、`副本`、`未命名`。

## 3. 扩展名

- 保留原格式：PNG 仍为 `.png`，JPEG 仍为 `.jpg` / `.jpeg`。
- 文件名统一 UTF-8；避免 `:`、`?`、`*`、`<`、`>`、`|`、`/`。
- 空格用 `-` 或去掉。

## 4. README

每个角色 README 只需要：

1. 一句话定位；
2. 基础 / 乐队 / 万圣节 / 变体与原作者；
3. 设定图表格（文件、设定、类型、作者）；
4. 归类说明与授权。

根 README 只放：简介、角色索引、目录结构、命名、作者对应、授权。
